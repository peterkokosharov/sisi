# Icons

The bolonka dog icon set for Sisi, own work, MIT (see ../../LICENSE).

- `sisi.ico` - Windows, embedded into sisi.exe (`packaging/sisi.rc`)
- `sisi.icns` - macOS, copied into the .app Resources
- `hicolor/` - Linux icon theme tree (PNG sizes + scalable SVG)
- `sisi.desktop` - Linux desktop entry

`resources/sisi.svg` (the window icon) is the same drawing as `hicolor/scalable/apps/sisi.svg`.
